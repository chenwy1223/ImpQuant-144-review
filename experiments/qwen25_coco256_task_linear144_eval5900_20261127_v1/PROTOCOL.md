# 256 图 W3A16 uniform 上的任务监督一阶全局 144 码

使用已独立核验的 Qwen2.5-VL-7B-Instruct 新基线和六个原生量化网格。校准使用同一份冻结的 256 张 COCO 图文对。起点为六任务 75.219% 的 196 模块 W3A16 uniform 伪量化状态。

使用与旧任务监督 144 码相同的 S64。ScienceQA 和 A-OKVQA 各 16 道选择题，TextVQA 16 道开放题，DocVQA 和 HME100K 各 8 道开放题。选择题使用原生生成首步正确选项的交叉熵。开放题使用正确答案 token 的平均交叉熵。在新模型上按照原逐模块反传路线重算 384 份原生 BF16 梯度，要求无梯度参考与反传前向逐位一致。各组以当前模型的组均答案损失归一化，四组等权。按 −gΔw 排名，Δw 是相邻整数码解码到 BF16 后的实际步长。

六个 v_proj 层索引为 7、11、15、19、23、27。扫描符合原规则的内部整数码坐标，每模块保留前 128 个坐标和两个有效方向。六层共选 144 个互异坐标，每层最多 96 个。沿用 scale、零点、分组和所有输入缩放，码位变化为一步。封存选择、预测收益及实际权重后进入正式评测。

在原封存的 5,900 题上评测新改码模型。使用此前逐题结果构成 256 图未修复和旧 8 图＋任务监督 144 码对照。六任务分别复测一题验证 256 图新基线的生成连续性。保留原图、输入、生成和本地判分。MMMU 为官方验证集 900 题，其余每项 1,000 题。报告每任务正确数或共识软分、升降持平题数、首步 EOS 和空答数，以及新 144 码相对两个对照的六任务等权宏分和 20,000 次配对 bootstrap 区间。按题和按图像组均复算。该题集已在前期开发中见过。

沿用 GPU 0 的 60 秒稳定空闲准入、40 GiB RAM 和 55 GiB 磁盘准入。运行时 8 GiB RAM、40 GiB 磁盘和 22.5 GiB allocated 保护不变。单一 GPU 工作进程。终态重新校验所有锁绑定，独立复算梯度汇总、合法全局排名、真实改码权重、三组原始输出及配对差值。逐文件验证本地静态证据。原始监督梯度留在服务器并记录大小及 SHA-256。
